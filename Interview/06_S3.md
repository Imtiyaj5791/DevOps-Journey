# 📦 S3 Interview Questions - Part 01

---

# Q1. What is Amazon S3?

## Answer

Amazon S3 (Simple Storage Service) is an object storage service provided by AWS.

It is used to store and retrieve files such as documents, images, videos, log files and application backups.

In my project, we use S3 for storing application backups, log files and snapshots.

---

# Q2. What is an S3 Bucket?

## Answer

An S3 Bucket is a container used to store objects in Amazon S3.

Every object is stored inside a bucket.

Bucket names must be globally unique across AWS.

---

# Q3. What is an Object in S3?

## Answer

An Object is the actual file stored inside an S3 bucket.

Every object consists of:

- Object Data
- Metadata
- Object Key (File Name)

Example:

```
backup.sql
image.png
logs.zip
```

---

# Q4. What are S3 Storage Classes?

## Answer

AWS provides different storage classes based on cost and access frequency.

Some commonly used storage classes are:

- S3 Standard
- S3 Intelligent-Tiering
- S3 Standard-IA
- S3 One Zone-IA
- S3 Glacier Instant Retrieval
- S3 Glacier Flexible Retrieval
- S3 Glacier Deep Archive

For frequently accessed data, we use **S3 Standard**.

For backup and archive, Glacier storage classes are commonly used.

---

# Q5. What is Versioning?

## Answer

Versioning keeps multiple versions of the same object.

If a file is accidentally deleted or overwritten, we can restore the previous version.

For important production buckets, Versioning is recommended.

---

# Q6. What is an S3 Lifecycle Policy?

## Answer

Lifecycle Policy automatically moves or deletes objects based on defined rules.

For example:

- Move old files to Glacier after 90 days.
- Delete temporary files after 30 days.

This helps reduce storage costs.

---

# Q7. What is S3 Encryption?

## Answer

S3 Encryption protects data stored inside the bucket.

AWS supports:

- SSE-S3
- SSE-KMS
- SSE-C

For production buckets, we generally use server-side encryption.

---

# Q8. What is the difference between Bucket Policy and IAM Policy?

## Answer

### IAM Policy

Controls what actions a User, Group or Role can perform.

### Bucket Policy

Controls who can access a specific S3 Bucket.

IAM Policy is attached to identities.

Bucket Policy is attached to the bucket.

---

# Q9. What is Block Public Access?

## Answer

Block Public Access is a security feature that prevents public access to S3 buckets.

It helps protect sensitive data from accidental exposure.

For production buckets, Block Public Access should normally remain enabled unless public access is specifically required.

---

# Q10. What is Static Website Hosting?

## Answer

S3 can host static websites.

It supports HTML, CSS and JavaScript files.

For dynamic applications, services like EC2 or ECS are used.

# Q12. How do you troubleshoot an "Access Denied" error while accessing an S3 bucket?

## Answer

First I verify whether the issue is affecting one user or multiple users.

Then I verify the IAM User or IAM Role permissions.

I check whether the required S3 policy is attached.

Then I verify the Bucket Policy.

If the bucket is encrypted using KMS, I verify the KMS permissions.

I also check whether Block Public Access or any Explicit Deny policy is causing the issue.

If required, I review CloudTrail logs to identify recent permission changes.

Finally, after approval, I restore the required access, verify the user can access the bucket and update the Jira ticket.

# 📦 S3 Interview Questions - Part 02 (Advanced)

---

# Q13. What is Cross Region Replication (CRR)?

## Answer

Cross Region Replication (CRR) automatically copies objects from one S3 bucket to another bucket in a different AWS Region.

It is mainly used for:

- Disaster Recovery
- High Availability
- Compliance Requirements

Versioning must be enabled on both buckets before configuring CRR.

---

# Q14. What is Same Region Replication (SRR)?

## Answer

Same Region Replication (SRR) copies objects between two buckets within the same AWS Region.

It is mainly used for:

- Log aggregation
- Data sharing
- Compliance
- Backup within the same region

Versioning must be enabled on both buckets.

---

# Q15. What is a Pre-Signed URL?

## Answer

A Pre-Signed URL allows temporary access to a private S3 object.

Even if the object is private, anyone with the generated URL can access it until the URL expires.

It is commonly used to securely share files without making the bucket public.

---

# Q16. Explain SSE-S3, SSE-KMS and SSE-C.

## Answer

### SSE-S3

Encryption keys are managed by AWS.

Easy to configure.

---

### SSE-KMS

Encryption keys are managed using AWS KMS.

Provides better security, auditing and access control.

Mostly used in production environments.

---

### SSE-C

The customer provides the encryption key during every request.

AWS does not store the encryption key.

---

# Q17. What happens if Versioning is enabled and you delete a file?

## Answer

When Versioning is enabled, deleting an object does not immediately remove it.

AWS creates a **Delete Marker**.

Previous object versions remain available and can be restored if required.

---

# Q18. What is Object Lock?

## Answer

Object Lock prevents objects from being deleted or modified for a specified retention period.

It is mainly used for compliance and regulatory requirements.

---

# Q19. What is Multipart Upload?

## Answer

Multipart Upload divides a large file into multiple parts.

Each part is uploaded independently.

After all parts are uploaded, AWS combines them into a single object.

It improves upload speed and allows failed parts to be uploaded again without restarting the complete upload.

---

# Q20. What is S3 Transfer Acceleration?

## Answer

S3 Transfer Acceleration improves upload and download performance by using AWS Edge Locations.

It is useful when users upload files from different geographical locations.

---

# Q21. What are S3 Event Notifications?

## Answer

S3 Event Notifications generate events whenever actions occur in a bucket.

Examples:

- Object Created
- Object Deleted

These events can trigger:

- AWS Lambda
- Amazon SNS
- Amazon SQS

---

# Q22. A user accidentally deleted a file from S3. What will you do?

## Answer

First I verify whether Versioning is enabled on the bucket.

If Versioning is enabled, I restore the previous version of the object.

If Versioning is not enabled, I check whether a backup or replication copy is available.

Finally, I verify that the user can access the restored file and update the incident ticket.

---

# Q23. EC2 cannot access an S3 Bucket. What will you check?

## Answer

First I verify whether the EC2 instance has the correct IAM Role attached.

Then I verify the IAM Role permissions.

Next I verify the Bucket Policy.

If the bucket uses KMS encryption, I verify the KMS permissions.

I also check whether any Explicit Deny policy exists.

If required, I review CloudTrail logs.

Finally, I verify that the EC2 instance can access the bucket successfully.

---

# Q24. What storage class do you recommend for backups?

## Answer

It depends on how frequently the backups are accessed.

- Frequently accessed backups → S3 Standard
- Infrequently accessed backups → Standard-IA
- Long-term archive → Glacier Flexible Retrieval or Glacier Deep Archive

The storage class should be selected based on business and recovery requirements.

---

- Business approval

- Bucket name
- Versioning status
- Backup availability
- Lifecycle policy

Only after confirmation do I delete the object.

## Answer

Whenever I receive an S3 issue, I first identify the exact problem.

Then I verify:

- IAM User or IAM Role
- IAM Policy
- Bucket Policy
- Bucket Encryption

Finally, I verify the issue is resolved and update the Jira ticket.

# Q28. Explain one S3 production issue you handled.

## Answer

One user reported that he was getting an "Access Denied" error while uploading a backup file to an S3 bucket.

First I verified the IAM Role attached to the EC2 instance.

Then I checked the IAM Policy and Bucket Policy.

I found that the required S3 PutObject permission was missing.

After approval, I updated the required IAM permissions.

Then I verified the upload from the EC2 instance.

The backup completed successfully.

Finally, I updated the Jira ticket and documented the RCA.

# Q30. Why is Versioning important in production?

## Answer

Versioning protects data from accidental deletion and overwriting.

If a file is deleted or modified by mistake, we can restore the previous version.

For important production buckets, enabling Versioning is considered a best practice because it improves data protection and recovery.
